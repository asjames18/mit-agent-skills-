# Research Standard

Use this reference when a draft depends on current events, technical claims, statistics, market information, or another factual assertion that can drift.

## Source order

Prefer sources closest to the underlying event or evidence:

1. Official documentation, standards, filings, datasets, and public records
2. Original research and first-party announcements
3. Direct public statements from responsible participants
4. High-quality secondary reporting for context or independent confirmation
5. Social posts only when the post itself is the relevant primary statement

Do not treat search-result snippets, unsourced summaries, reposts, or generated answers as proof.

## Evidence record

For each material claim, capture:

- Claim
- Source owner and URL
- Source type
- Event or effective date
- Publication or update date
- Date checked
- Claim classification
- Whether it is time-sensitive
- Contradicting or qualifying evidence
- Safe wording and confidence

Separate the event date from the publication date so old events are not presented as breaking news.

## Interpretation

State what the source establishes before adding interpretation. Label inference clearly. Do not invent the represented person's opinion; request it when a draft would otherwise attribute a new or sensitive position to them.

For high-stakes financial, legal, medical, safety, or security claims, use current authoritative sources, narrow the wording to what is supported, and surface uncertainty or professional-review needs.

## Stopping conditions

Return `NEEDS CONFIRMATION` when owner knowledge could settle an important factual or disclosure question. Return `NO POST RECOMMENDED` when a central claim cannot be verified, the material is stale without a current angle, or the available sources are too weak to support responsible public copy.
